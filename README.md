# User Authentication System

A React-based user authentication system with form validation and page navigation functionality.

## Features
- User registration form
- Input validation
- Error handling
- Secure password field
- React Router navigation
- Display submitted user details
- Responsive user interface

## Technologies Used
- React.js
- React Router DOM
- JavaScript
- CSS

## Authentication Fields
- First Name
- Last Name
- Username
- Email
- Password
- Phone Number
- Country
- City
- PAN Number
- Aadhaar Number

## Project Workflow
1. User enters registration details.
2. Form validations are performed.
3. Valid data is submitted successfully.
4. User is redirected to the details page.
5. Submitted information is displayed.

## Concepts Used
- React Hooks (`useState`)
- Form Handling
- Input Validation
- Routing in React
- State Management
